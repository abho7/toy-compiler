# The corpus

Programs in minic, each with the exact behaviour it must produce.

Every phase after the reference interpreter is judged against these: the IR interpreter and the
VM run the same programs, at every optimization level, and must produce **byte-identical**
observations. A pass that changes any byte of any file here has changed what a program does.

## The golden format

A `.expected` file holds the program's output bytes, then one trailer line:

```
5
hello
=== exit 0
```

The trailer is the rest of the observable behaviour, as docs/semantics.md defines it:

| trailer | meaning |
|---|---|
| `=== exit N` | finished cleanly; `N` is main's return value reduced into 0-255 |
| `=== trap KIND at LINE:COL` | aborted; the kind and where it happened are both part of the behaviour |
| `=== budget exceeded after N steps` | the harness stopped it; never a program behaviour, and no corpus program may produce it |

Output and trailer are compared as one byte string, so all three parts of observable behaviour —
the output, the outcome, and the exit status — are checked by a single comparison rather than by
three assertions that could each be forgotten.

## The goldens are written by hand

Every `.expected` file was written from a value known independently of this compiler: sorted
arrays, `fib(20) = 6765`, the four solutions to six queens, the primes below 30, the trap
positions read off the source. **They are not generated by running the interpreter.** A golden
produced by the thing it checks pins current behaviour without verifying it, which would make
this corpus a regression test only and not evidence of correctness.

`node tools/goldens.js` checks every program against its golden. `--update` rewrites them, and
is for after a deliberate change to the language or the format — the diff it produces is the
thing to review, not to wave through.

## Adding a program

Write the `.mc` file, work out the expected output by hand, write the `.expected` file, and run
the checker. A disagreement means one of the two is wrong, and finding out which is the point.
